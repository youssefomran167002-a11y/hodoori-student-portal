# ANU — بوابة كروت الحضور الذكية للطلاب 🎓

البوابة الرسمية المستقلة لكروت الحضور الذكية للطلاب لنظام **ANU**.

## 🚀 المميزات:
- عرض كروت الـ QR الأصلية بتقنية **Vector SVG** لمنع أي تشويش أو ضغط.
- بحث فوري بالاسم أو الكود التسلسلي أو الفصول.
- وضع الحضور الذكي بملء الشاشة مع أقصى تباين وسطوع لتسريع مسح الكاميرا.
- إمكانية حفظ الكارت في الاستوديو بدقة فائقة **Ultra-HD (1200x1440)**.
- إمكانية مشاركة الكارت المباشر عبر واتساب.
- لا يتطلب أي تسجيل دخول أو حساب من الطالب.
